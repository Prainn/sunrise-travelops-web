# 云南团务地图运行时素材

首页云南团务地图使用的静态素材，从工作区根 `docs/maps/yunnan/`（2026-10-26 版）复制；根 docs 不随本仓库发布，更新时三份文件须一起替换。

| 文件 | 用途 |
| --- | --- |
| `yunnan-regions.svg` | 16 州市闭合区域，viewBox `0 0 1050 1100`；path `name` 为六位行政代码，注册为 ECharts SVG 地图 |
| `regions.json` | 行政代码与中文州市名；行政区域不是业务目的地城市 |
| `display-points.json` | 6 个公共目的地在本版 SVG 上的平面坐标及 WGS84 校验坐标 |

## 来源

底图：云南省地图院编制，云南省自然资源厅监制（原图：云S(2026)49号）。SVG 仅提取原图区域路径并移除文字与道路，审图号指原图，衍生 SVG 未另行送审。

目的地经纬度为 WGS84：© OpenStreetMap contributors（ODbL）、GeoNames（CC BY）、Wikidata（CC0）。

## 点位校准

`points[].svg` 由原图 5 个印刷城市符号人工配准，巴拉格宗由控制点拟合插值；`affine` 只记录现有控制点范围的展示配准，不是全省通用投影，前端不得用它外推新地点，也不能把经纬度直接当 SVG x/y。

前端按 `devResourceCityId`（仅开发环境 ID）或公共城市精确中文名匹配，且接口经纬度必须与本文件一致才使用静态点；新增或改坐标的城市显示“地图点位待校准”，需补配准后更新本文件。
