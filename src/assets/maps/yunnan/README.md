# 云南团务地图运行时素材

首页云南团务地图使用的静态素材，从工作区根 `docs/maps/yunnan/`（底图2026-10-26、16城点位2026-10-27版）复制；根 docs 不随本仓库发布，更新时三份文件须一起替换。

| 文件 | 用途 |
| --- | --- |
| `yunnan-regions.svg` | 16 州市闭合区域，viewBox `0 0 1050 1100`；path `name` 为六位行政代码，注册为 ECharts SVG 地图 |
| `regions.json` | 行政代码与中文州市名；行政区域不是业务目的地城市 |
| `display-points.json` | 16 个公共目的地在本版 SVG 上的平面坐标及 WGS84 校验坐标 |

## 点位校准

`points[].svg` 中15个城市对照原图印刷城市符号人工配准，巴拉格宗由原5个控制点拟合插值；`affine` 只记录原有控制点范围的展示配准，不是全省通用投影，前端不得用它外推新地点，也不能把经纬度直接当 SVG x/y。

前端按 `devResourceCityId`（仅开发环境 ID）或公共城市精确中文名匹配，且接口经纬度必须与本文件一致才使用静态点；新增或改坐标的城市显示“地图点位待校准”，需补配准后更新本文件。
