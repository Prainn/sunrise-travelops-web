# 云南团务地图运行时素材

首页静态素材源于工作区根 `docs/maps/yunnan/`：底图2026-10-26，49个展示点2026-10-27。根docs不随前端发布，素材保持与同版SVG一致。

| 文件 | 用途 |
| --- | --- |
| `yunnan-regions.svg` | 16州市闭合区域，viewBox `0 0 1050 1100`，path `name`为行政代码 |
| `regions.json` | 行政代码与州市名，行政区域与业务目的地不是同一层级 |
| `display-points.json` | 原16点及新增33个云南目的地的静态SVG坐标与WGS84校验坐标 |

原15点来自印刷城市符号，巴拉格宗保留原5控制点插值。新增33点以15个符号控制点离线仿射配准并叠加最近4点的距离平方反比残差修正；控制点留一验证最大8.765、均方根4.539 SVG单位。全部新增点核对所在州市；泸沽湖/奔子栏作省界附近展示微调，保留调整前值，业务经纬度不变。该省级示意图不是已知投影，不用于导航。

运行时只使用已登记静态点，不能利用配准参数外推新地点。按非空 `devResourceCityId` 或精确中文名匹配；无已核对开发ID时为null，不使用生产ID冒充开发ID。经纬度变化仍显示“地图点位待校准”。45个生产云南目的地均已覆盖，省外目的地暂不扩入。

离线重建入口为根 `docs/maps/yunnan/register-supplemental-points.py`；原EPS重建脚本完成原16点后也会调用该入口，避免覆盖补充清单。
